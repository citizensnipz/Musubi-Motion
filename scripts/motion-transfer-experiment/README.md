# MT17 offline motion-transfer experiment

This directory is an original Apache-2.0 experiment. It has no editor entry point and adopts no retargeting runtime. It uses existing Three.js 0.180.0 (MIT) math and the installed `SkeletonUtils.retargetClip` comparator. No dependencies, external assets, models or training data were added.

Run from the repository root (Node22, installed dependencies):

```powershell
node scripts/motion-transfer-experiment/generate.mjs
$env:MT17_EVIDENCE='D:/your/task-evidence'
npx vitest run tests/motion-transfer-experiment.test.ts --no-cache --fsModuleCachePath D:/your/task-cache --pool=threads --maxWorkers=1 --no-file-parallelism
npx tsc --noEmit
npx tsc --noEmit --target ES2022 --module ESNext --moduleResolution Bundler --lib 'ES2022,DOM' --strict --skipLibCheck --allowImportingTsExtensions scripts/motion-transfer-experiment/harness.ts
```

The generator deterministically authors `MT17-SOURCE-24.fbx` and `MT17-reference.json`. Set `MT17_REFRESH=1` for one test run to regenerate the four version-independent native character descriptors; normal tests compare these checked-in descriptors with the generator. Descriptors contain owned joints, reference, mesh bindings and coordinate metadata. Tests create the current native scene with `emptyScene()` and save/reopen actual current-format MSB archives. `MT17_EVIDENCE` is optional; without it tests write nothing. The core harness is strictly type-checked separately because the product tsconfig includes only `src`. The test file follows the existing Vitest execution path; standalone type-checking that Node-based file requires Node types absent from the existing dependency tree.

The source has 17 explicit semantic roles, meters, Y-up/+Z forward, independent T reference and a two-second 24fps root/step/arm performance. FBX `UnitScaleFactor=100` means100 centimeters per source unit, i.e.1m per unit. Reference hips height0.9 differs from animated frame0 height0.84. Stance intervals come from the original procedural authoring function. No pose or contact labels are inferred from the animated first frame.

The native targets are identity, uniform0.8 scale, unequal proportions, and a25-degree Y-axis change to upper-arm reference frames with inverse child orientation/offsets. Their IDs are independent of imported source IDs. The diagnostic skin is one triangle bound to hips/left hand/left foot; it is sufficient for persistence/deformation checks and carries no character/splat quality claim.

Mapping explicitly validates17 roles, ID bijection, hierarchy, reference, finite data, supplied proper coordinate basis/units, fixed0..48 at24fps, Base-only documents and unoccupied targets. It rejects unsupported intermediate bones, non-root translation animation, scale animation, unbaked/nonuniform/reflected scale and independent animated skinned-node transforms. Constant uniform scale must already be represented in units/offsets, as the existing FBX importer does. Unit-normalized1e-7m rest-translation tolerance accounts for imported float precision. Non-root Bezier curves must keep every effective control value within that rest tolerance, using the existing tangent/weight semantics; the convex-hull bound conservatively covers continuous time between all keys rather than relying on samples. The name-addressed comparator additionally requires nonempty unique names in both source and target document/reference lists before allocating adapters. All normalization/mapping/comparator adapters are transient. Target authored joints and binding data remain unchanged.

The original mapper applies source reference-relative world quaternion deltas to target reference-world quaternions, solves parent-first through static orientation, unwraps Euler XYZ and bakes ordinary Base tracks. Root displacement is leg-length-scaled, anchored to the target reference root after subtracting source frame0 position. This specified policy deliberately removes the source's initial vertical placement. The comparator receives explicit target-name to source-name mapping, source hip, FPS, global reference offsets, hip displacement offset/scale and position preservation settings. It uses48 endpoint-inclusive samples spaced2/47 seconds; the importer uses49 spaced1/24 seconds. Metrics evaluate by time, never by matching array indices.

Pass/fail assertions verify harness mechanics and analytic identity/scale baselines. They do not assert that every mapping meets every diagnostic gate. In the initial baseline experiment the original mapper satisfies identity/scale pose gates, while the helper's maximum angular discrepancy is about0.805degrees. The basis fixture reveals fractional Euler bake interpolation error separately from integer-grid mapping accuracy. Slip and penetration pass the exploratory0.02/0.01 leg-length gates in this fixture, yet the specified root anchor lifts stance feet about0.067 leg lengths above the floor. A passing slip/penetration gate is therefore insufficient for contact quality or adoption. Unequal-proportion hand/head deviations are diagnostics without paired ground truth. Any later contact correction, general topology support or editor workflow requires another task.

Private run reports contain exact hashes, per-foot stance RMS/max/penetration/boundary metrics, per-joint and hand/head deviations, source parser errors, timing, reference matrices/ID maps, trajectories and native baked archives. Re-run affected tests on the integrated evaluator/schema before claiming compatibility with later product changes. No UI/browser verification is applicable to this offline-only task.

## Offline anchoring and grid calibration

`calibration.ts` adds explicit `frame0-to-target-reference` and `reference-relative-xyz` policies outside the original harness. Both are required arguments. The original mapper/helper and all owned fixtures remain unchanged. The alternative adds `(sourceFrame0Root - sourceReferenceRoot) * legRatio` in canonical meters to the existing root tracks, then converts through the target basis/units. This retains all XYZ components. It neither infers contacts nor locks feet.

Run the generator and original tests first, then:

```powershell
$env:MT17_CALIBRATION_EVIDENCE='D:/your/calibration-evidence'
node node_modules/vitest/vitest.mjs run tests/motion-transfer-experiment.test.ts tests/motion-transfer-calibration.test.ts --no-cache --no-fsModuleCache --pool=threads --maxWorkers=1 --no-file-parallelism
node node_modules/typescript/bin/tsc --noEmit --target ES2022 --module ESNext --moduleResolution Bundler --lib 'ES2022,DOM' --strict --skipLibCheck --allowImportingTsExtensions scripts/motion-transfer-experiment/harness.ts scripts/motion-transfer-experiment/calibration.ts
```

Tests compare integer0..48 and fractional0.25,7.125,23.5,47.75 in deterministic shuffled order. Per-foot authored stance records include horizontal RMS/max, signed-floor-distance RMS/absolute max, positive clearance, penetration and boundary epsilon variation. Slip0.02 and penetration0.01 leg-length gates are retained; a separate exploratory symmetric absolute floor-distance0.01 gate flags floating feet as well as penetration. Endpoints0/48 have no outside-clip continuity measurement (reported0 sentinel). These sampled gates cannot certify continuous contact, unseen motions or production quality.

The measured r180 `fps:24` path still emits48 endpoint-inclusive samples spaced2/47 seconds. A separate adapter explicitly requests `fps:24.5` from the same unmodified installed helper to obtain49 endpoint-inclusive samples near1/24 seconds. This parameter is a diagnostic choice, not a24fps upstream fix or adopted default. Tests inspect every actual emitted time and count, and reproduce the existing48 path as an adapter control. Both receive the same49 source samples from the native evaluator. Input Float32 position interpolation is linear and local quaternion interpolation is slerp; helper output is resampled into49 unwrapped native XYZ linear keys. The helper's last source update is1e-7 seconds short of2 seconds. Comparisons use common physical times (the union of both grids and prescribed fractional times), including endpoints, never matching indices.

Initial calibration flags frame0-anchor floor distance0.06672 leg lengths (PROPORTION0.07407). Reference-relative XYZ reduces the original identity/scale/BASIS sampled floor distance below0.000175 and PROPORTION below0.007402 leg lengths; proportion slip remains0.01567 and has no paired ground truth. Passing these exploratory gates does not imply a correct transfer. The48-vs49 helper grid difference reaches0.804945 degrees and0.006322 meters on identity/BASIS, while endpoint differences between those helper paths are zero. The aligned49-to-original-bake discrepancy stays below0.000009 degrees on this owned clip; this separates this clip's sampling loss from broader retargeting accuracy. Neither helper sampling nor either root policy becomes product behavior.

Calibration tests preserve authored reference/binding/fallback data, replay deterministically, verify fresh Base-only one-commit undo/redo, and save/reopen current native archives and skin deformation for all four targets, both policies and all three measured paths.
